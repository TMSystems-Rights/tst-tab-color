## 1. 本書の目的

v1.0.0（AMO 承認済み）に対する **追加機能仕様** を確定し、実装の拠り所とする。
既存機能の挙動・データモデル・CSS クラス設計は、本書に明記した差分以外はそのまま維持する。

## 2. 追加機能サマリ

| # | 追加項目 | 概要 |
|---|---------|------|
| A | フォントのプレビュー表示 | オプション画面の入力フォームに、指定フォントのプレビューエリアを追加する |
| B | アクティブ／ホバー時のフォント色 | アクティブ／ホバー時の前景色を任意指定可能にする（省略時は既存の色反転制御に従う） |
| C | アクティブ／ホバー時の背景色 | アクティブ／ホバー時の背景色を任意指定可能にする（省略時は既存の色反転制御に従う） |
| D | 色選択への透過度対応 | フォント色・背景色（通常時／アクティブ時）すべてに α（アルファ）を指定可能にする |

## 3. データモデル拡張

### 3.1 TcRule の拡張

```js
// v1.0.0（既存）
{
  id:              string,      // UUID
  pattern:         string,
  patternType:     'prefix' | 'regexp',
  fontFamily:      string,      // ブランク可
  fontColor:       string,      // ブランク可（#rgb | #rrggbb）
  backgroundColor: string,      // ブランク可（#rgb | #rrggbb）
}

// v1.1.0（追加後）
{
  id:                    string,
  pattern:               string,
  patternType:           'prefix' | 'regexp',
  fontFamily:            string,  // ブランク可
  fontColor:             string,  // ブランク可（#rgb | #rrggbb | #rgba | #rrggbbaa）
  backgroundColor:       string,  // ブランク可（4形式）
  activeFontColor:       string,  // ★新規 ブランク可（4形式、省略時 invert(bg) にフォールバック）
  activeBackgroundColor: string,  // ★新規 ブランク可（4形式、省略時 invert(bg) にフォールバック）
}
```

### 3.2 後方互換

- v1.0.0 で保存されたルールは `activeFontColor` / `activeBackgroundColor` プロパティを持たないが、
  読み込み時は「未指定 = 既存の反転ロジック適用」と同等に動作するため、マイグレーション処理は**不要**。
- 保存時は新プロパティを含めた全フィールドを常に出力する（空文字列含む）。

## 4. 色の透過度対応（機能 D）

### 4.1 受理するカラーコード形式

| 形式 | 例 | 説明 |
|------|-----|------|
| `#rgb` | `#f0a` | 3桁（α なし、既存） |
| `#rrggbb` | `#ff00aa` | 6桁（α なし、既存） |
| `#rgba` | `#f0a8` | 4桁（α 1桁、v1.1.0 新規） |
| `#rrggbbaa` | `#ff00aa80` | 8桁（α 2桁、v1.1.0 新規） |

### 4.2 UI 構成（カラー入力欄 1件分）

```
┌──────────────────────────────────────────────────────────────┐
│ [#rrggbbaa テキスト] [🎨ピッカー] [━━━●━━━] α: 80%     │
└──────────────────────────────────────────────────────────────┘
```

- **テキスト入力**: 4形式いずれも受理。保存値はユーザー入力のまま（例：`#ff00aa80`）
- **カラーピッカー（`<input type="color">`）**: RGB 部分のみを編集。アルファ非対応のためスライダーと併置
- **アルファスライダー（`<input type="range" min="0" max="100" value="100">`）**: α を 0〜100% で指定
- **α 数値表示**: スライダー右に `80%` 等を表示

### 4.3 連動ロジック

| 操作 | 連動先 |
|------|--------|
| テキスト欄に入力 | ピッカー・スライダーへ反映（妥当値のみ、不正時は赤枠） |
| ピッカー変更 | テキスト欄に反映（既存 α を維持） |
| スライダー変更 | テキスト欄の α 部分を書き換え（RGB は維持） |

- α 100% 時のテキスト表示は **`#rrggbb`（6桁）を優先** し、不透明度 100% 未満のときのみ 8桁 `#rrggbbaa` を表示する
- 内部正規化関数 `NormalizeColorToHex8(value)` を追加（`#rgb` → `#rrggbbff`、`#rgba` → `#rrggbbaa` 等）

### 4.4 バリデーション

- 正規表現: `/^#([0-9a-fA-F]{3}|[0-9a-fA-F]{4}|[0-9a-fA-F]{6}|[0-9a-fA-F]{8})$/`
- ブランクは引き続き有効（未指定扱い）

## 5. オプション画面レイアウト

### 5.1 フォーム配置（上から順）

| # | 項目 | 状態 |
|---|------|------|
| 1 | URLパターン | 既存 |
| 2 | フォント（入力欄直下に**フォントプレビュー**を配置）★ | 既存 + プレビュー新規 |
| 3 | 種別 | 既存 |
| 4 | フォント色 | 既存（透過度対応に拡張） |
| 5 | 背景色 | 既存（透過度対応に拡張） |
| 6 | **アクティブ／ホバー時フォント色** | ★新規 |
| 7 | **アクティブ／ホバー時背景色** | ★新規 |

※ 実装修正（2026-04-24）: フォントプレビューはフォント入力欄と同じグリッドセル内に配置する。これは、プレビューを独立した grid アイテムにすると `display: none` 時に後続要素が繰り上がりレイアウト崩れが発生するため。アクティブ／ホバー時プレビューは不要として**削除**。

### 5.2 プレビューエリア仕様

- **対象はフォント（書体）のみ**。フォント色・背景色はプレビューに反映しない
- **表示条件**: フォント欄に値が入力されている時のみ表示。空欄時はプレビューエリア自体を**非表示（`display: none`）**
- **配置**: フォント入力欄の直下（同じグリッドセル内）に1箇所のみ
- **サンプル文（ja ロケール）**:
  ```
  1234567890
  abcdefghij
  ABCDEFGHIJ
  あいうえお
  アイウエオ
  ①②③④⑤
  このフォントで如何ですか？
  ```
- **サンプル文（en ロケール）**:
  ```
  1234567890
  abcdefghij
  ABCDEFGHIJ
  !@#$%^&*()
  The quick brown fox
  jumps over the lazy dog.
  How does this font look?
  ```
- サンプル文は `_locales/{ja,en}/messages.json` にキー `optionsFontPreviewSample` で登録
- プレビュー要素は `<pre>`（改行保持）を使用
- プレビュー文字サイズは 14px 程度、パディング 8px、枠線 1px でカード表示

### 5.3 テーマ（ライト／ダーク）への追従

- プレビューエリアの背景・文字色は既存の CSS 変数（`--tm-bg-surface` / `--tm-fg-page` 等）を使用し、
  ライト／ダーク両テーマで視認性を確保する

## 6. ルール一覧テーブル

### 6.1 表示方針

既存列数（URLパターン・種別・フォント・フォント色・背景色・編集・削除）を**維持**し、
「フォント色」「背景色」の各セル内で**通常色とアクティブ色を縦積み 2 段**で表示する。

### 6.2 セル内レイアウト

```
┌─────────────────┐
│ ■ #ff00aa       │ ← 1段目：通常色（fontColor / backgroundColor）
│ ■ #ffaa00       │ ← 2段目：アクティブ色（activeFontColor / activeBackgroundColor）
└─────────────────┘
```

- 通常色が未指定なら 1段目を空に、アクティブ色が未指定なら 2段目を空にする
- スウォッチ + カラーコードの並びは既存踏襲
- α 指定時はスウォッチ背景に α を反映（チェッカーボード背景を薄く敷くのが理想、未指定時は通常背景）
- 表示文字列は保存値（ユーザー入力）をそのまま出力（例：`#ff00aa80` / `#f0a`）

## 7. CSS 生成ロジック（background.js）

### 7.1 通常時

既存と同一。以下の 4 指定を出力する（各プロパティが指定されている時のみ）：

- `.tab.tm-rule-{n} .background { background-color: {backgroundColor}; }`
- `.tab.tm-rule-{n} { --tab-text: {fontColor}; }`
- `.tab.tm-rule-{n} .label { color: {fontColor}; font-family: {fontFamily}; }`

### 7.2 アクティブ／ホバー時（拡張）

現行は `backgroundColor` 指定時のみ `invert(bg)` を出力している。v1.1.0 では以下のルールで生成する：

| backgroundColor | activeBackgroundColor | 出力する背景色 |
|-----------------|----------------------|---------------|
| 指定あり | 指定あり | `activeBackgroundColor` |
| 指定あり | 未指定 | `invert(backgroundColor)`（既存挙動） |
| 未指定 | 指定あり | `activeBackgroundColor` |
| 未指定 | 未指定 | 出力しない（TST 既定のホバー挙動） |

| fontColor 系 | activeFontColor | 出力する前景色 |
|--------------|----------------|---------------|
| `fontColor` 指定 or `backgroundColor` 指定 | 指定あり | `activeFontColor` |
| `backgroundColor` 指定 | 未指定 | `backgroundColor`（反転前の背景色。既存挙動） |
| いずれも未指定 | 指定あり | `activeFontColor` |
| いずれも未指定 | 未指定 | 出力しない |

### 7.3 適用セレクタ

既存踏襲：

- 背景 → `.tab.tm-rule-{n}:hover .background, .tab.tm-rule-{n}.active .background`
- 前景 → `.tab.tm-rule-{n}:hover, .tab.tm-rule-{n}.active` に `--tab-text` 書き換え
- 前景保険 → `.tab.tm-rule-{n}:hover .label, .tab.tm-rule-{n}.active .label` に `color`

### 7.4 α（透過度）の扱い

- CSS 出力時はヘックス形式をそのまま埋め込む（CSS Color Module Level 4 で 8 桁ヘックスは標準対応済）
- 例: `background-color: #ff00aa80;`
- 反転対象が α 付きの場合、α は維持し RGB 部分のみ反転する（`InvertColor` を 8 桁対応に拡張）
