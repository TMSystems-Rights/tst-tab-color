必須のコーディングルールを提示します

### HTML

- cssクラス名には接頭辞 `tm-` を付与するルールとします（ 例：`tm-c-rule-0` など）
- id属性値については接頭辞 `tm` を付与しキャメルケースとします（例：`tmTxtUrl` など）

### Javascript

- 基本的な構造は下記例のとおりオブジェクトとして名前空間や関数としてまとめる構造とします。

例：実際のプロジェクトに適した名前空間の構造にして構いません。

```javascript
const TMS_APP = {
	/**
	 * このファイル内限定の共通定数群
	 * @namespace Const
	 */

	Const: {
		/** ログメッセージ接頭辞 */
		LOG_PREFIX: '[MyApp]',
		/** 配列１ */
		ARRAY_1: [
			/** ほげ */
			HOGE: 'hoge',
			/** ふが */
			FUGA: 'fuga',
		],
		/** 配列２ */
		ARRAY_2: [
			/** ほげ */
			HOGE: {name: 'hoge', param: 'aaa'},
			/** ふが */
			FUGA: {name: 'fuga', param: 'bbb'},
		],
	},

	/**
	 * このファイル内限定の共通関数群
	 * @namespace ComFnc
	 */
	ComFnc: {
		/**
		 * 値が空かどうかを判定する
		 * @param {*} value 判定対象の値
		 * @returns {boolean} 判定結果（true: 空、false: それ以外）
		 */
		IsEmpty: function (value) {
			if (typeof value === 'undefined' || str === null) {
				return true;
			} else if (typeof value === 'string' && value.trim().length <= 0) {
				return true;
			}
			return false;
		},

		/**
		 * 値が空の場合は空文字列を返し、そうでない場合はそのまま返す
		 * @param {*} value 判定対象の値
		 * @returns {string} 判定結果（空の場合は空文字列、そうでない場合はそのままの値）
		 */
		ConvNull2Blank: function (value) {
			if (this.IsEmpty) {
				return TmCommon.Const.BLANK;
			}
			return value;
		}
	},

	/**
	 * 初期表示エントリーポイント
	 */
	Init: function () {
		...省略...
	}

	/**
	 * メイン画面に関する処理空間
	 * @namespace ComFnc
	 */
	ScreenMain: {
		...省略...
	},

	/**
	 * モーダル１画面に関する処理空間
	 * @namespace ComFnc
	 */
	ScreenModal1: {
		...省略...
	}
};

// 初期処理
MY_APP.Init();

```

- JQueryは最新版を使用してもOK。
- 各JSファイルで共有できる機能（定数、関数など）は共通JSにまとめ再利用する。
- JSDocは必ず記載する
- 定数名：原則、スネークケースとします（例：`const MY_APP = { ... };`, `const FONT_TYPE_DEFAULT = 'consolas';` など）
- グローバルな定数の名前空間（上記例だと `const TMS_APP`） は、接頭辞 `TMS_` を付与してください。
- 関数名：原則、アッパーキャメルとします（例：`GetParam: function(){ ... }, ` など）
- その他、`eslint.config.mjs` に記載のルールに従ってください。
