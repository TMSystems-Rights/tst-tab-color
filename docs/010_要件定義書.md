## 1. 背景・目的

Firefox 拡張機能 Tree Style Tab (TST) はタブをサイドバーにツリー形式で表示する。
しかし TST 標準機能では URLパターンに基づいたタブの背景色変更ができない。

本拡張機能 **tst-tab-color** は TST の External API を利用し、ユーザーが定義した
URLパターンに合致するタブの背景色をサイドバー上でリアルタイムに変更する。

## 3. スコープ

### 3.1 対象

- Firefox ブラウザ上の TST サイドバーに表示されるタブの背景色変更
- URLパターン（前方一致・正規表現）による色の自動付与
- ユーザーによる色ルール設定（追加・編集・削除・並び替え）

### 3.2 対象外

- Chrome / Edge など Firefox 以外のブラウザ
- TST 以外のサイドバー拡張機能との連携
- タブのテキスト装飾（下線・太字等）の変更
- ツリー構造の操作（インデント・並び替え等）

## 4. 機能要件

### FR-01: URLパターンによるタブ色付け


| #       | 要件                                                                     |
| ------- | ---------------------------------------------------------------------- |
| FR-01-1 | タブの URL が設定済みパターンに一致した場合、TST サイドバー上のそのタブにルールで指定したフォント・フォント色・背景色を適用すること |
| FR-01-2 | パターンの種別として「前方一致」および「正規表現」の2種類をサポートすること                                 |
| FR-01-3 | 複数パターンが一致する場合、ルール一覧の上位（優先順位が高い）ルールを適用すること                              |
| FR-01-4 | どのパターンにも一致しないタブは TST のデフォルト色のまま表示すること                                  |


### FR-02: リアルタイム反映


| #       | 要件                                        |
| ------- | ----------------------------------------- |
| FR-02-1 | タブが新規作成された際に即座に色付けを行うこと                   |
| FR-02-2 | タブの URL が変更（ナビゲーション）された際に即座に再評価・再色付けを行うこと |
| FR-02-3 | Firefox 起動・TST ロード時、既存の全タブに対して色付けを行うこと    |
| FR-02-4 | TST が再起動または再ロードされた場合、色付けを自動的に再適用すること      |


### FR-03: 色ルール設定


| #       | 要件                                                 |
| ------- | -------------------------------------------------- |
| FR-03-1 | ユーザーはオプションページからルールを追加・編集・削除できること                   |
| FR-03-2 | 各ルールは以下の項目で構成すること（詳細は下表参照）                         |
| FR-03-3 | ルールの適用優先順位をドラッグ＆ドロップで変更できること                       |
| FR-03-4 | 設定はブラウザの `storage.sync` に保存し、Firefox アカウントで同期されること |
| FR-03-5 | ルール数の上限は 100 件とすること                                |


**ルール構成項目**


| 項目      | 入力形式                | 規定値  | 説明                                          |
| ------- | ------------------- | ---- | ------------------------------------------- |
| URLパターン | テキストボックス            | ブランク | 照合する URL 文字列                                |
| パターン種別  | ラジオボタン（前方一致 / 正規表現） | 前方一致 | パターンのマッチング方式                                |
| フォント    | テキストボックス            | ブランク | CSS `font-family` の値。ブランクの場合はブラウザ設定に従う      |
| フォント色   | テキストボックス ＋ カラーピッカー  | ブランク | CSS `color` の値。ブランクの場合はブラウザ設定に従う            |
| 背景色     | テキストボックス ＋ カラーピッカー  | ブランク | CSS `background-color` の値。ブランクの場合はブラウザ設定に従う |


### FR-04: オプションページ


| #       | 要件                                                                |
| ------- | ----------------------------------------------------------------- |
| FR-04-1 | ツールバーアイコンのクリックでオプションページを開くこと                                      |
| FR-04-2 | オプションページにはルール一覧、追加フォーム、保存ボタンを配置すること                               |
| FR-04-3 | フォント色・背景色の入力にはカラーピッカー（`<input type="color">`）を使用し、テキストボックスと連動すること |
| FR-04-4 | 入力値のバリデーションを行うこと（正規表現の構文チェック、カラーコードの形式チェック）                       |
| FR-04-5 | フォント色・背景色・フォントがすべてブランクのルールは保存時に警告を表示すること（URLパターンのみのルールは無効のため）     |
| FR-04-6 | UI は日本語・英語の2言語に対応すること（i18n）                                       |

## 5. 非機能要件


| #      | 分類      | 要件                                                            |
| ------ | ------- | ------------------------------------------------------------- |
| NFR-01 | 互換性     | Firefox 最新安定版（Firefox 128 以降）で動作すること                          |
| NFR-02 | 互換性     | TST バージョン 4.0 以降の External API に対応すること                        |
| NFR-03 | パフォーマンス | タブ更新イベントから色付け完了まで 200ms 以内を目標とすること                            |
| NFR-04 | 安全性     | XSS を防ぐため、ユーザー入力の HTML エスケープを徹底すること                           |
| NFR-05 | 安全性     | 正規表現の ReDoS 対策としてパターン評価に タイムアウトを設けること                         |
| NFR-06 | 保守性     | 既存拡張機能（tst-multi-function-exporter）と同一のコーディング規約・フォルダ構成に準拠すること |
| NFR-07 | マニフェスト  | Manifest V3 を使用すること                                           |

## 6. 制約・前提条件


| #    | 内容                                                                     |
| ---- | ---------------------------------------------------------------------- |
| C-01 | ユーザーの Firefox に Tree Style Tab がインストールされていること                          |
| C-02 | TST の「他の拡張機能からの操作を許可」設定が有効になっていること                                     |
| C-03 | TST の ID は `treestyletab@piro.sakura.ne.jp` であること                      |
| C-04 | タブ色変更は TST の `add-tab-state` API と CSS 注入により実現すること（TST DOM の直接操作は行わない） |
| C-05 | ビルドツール（Webpack / Vite 等）は使用せず、Vanilla JS で実装すること                       |

## 7. 用語定義


| 用語           | 定義                                                 |
| ------------ | -------------------------------------------------- |
| TST          | Tree Style Tab。Firefox 拡張機能。タブをツリー形式でサイドバー表示する     |
| URLパターン      | タブの URL と照合する文字列（前方一致または正規表現）                      |
| ルール          | URLパターン＋背景色の組み合わせ。優先順位を持つ                          |
| タブ色付け        | TST サイドバー上のタブ要素の背景色を変更すること                         |
| External API | TST が他拡張機能向けに公開している `runtime.sendMessage` ベースの API |
